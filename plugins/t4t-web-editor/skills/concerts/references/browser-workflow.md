# Publicación mediante navegador autorizado

Usa las herramientas de navegador del entorno y observa el estado antes de actuar. Los índices de elementos cambian: nunca reutilices los de una ejecución anterior. Una sesión válida hoy puede caducar. Si hace falta login, conserva el trabajo y solicita sólo esa intervención.

## Bandsintown

1. Abre el panel del artista 15638928 y consulta próximos, borradores y eventos pasados cuando la fecha lo requiera.
2. Para un ID existente usa el enlace Editar observado en el menú de la fila. No pulses Duplicar.
3. Para un evento nuevo: Agregar evento → Concierto → Sede. Busca y selecciona el recinto existente, verificando ciudad/dirección. No crees una sede si ya existe.
4. Selecciona fecha con el calendario o formato ISO `2026-11-13`. La hora se muestra en la zona del recinto: 19:30 en Berlín. Las fechas con barras pueden mostrar una vista previa aparentemente correcta pero fallar al guardar.
5. Añade título, descripción con precio y URL oficial, y flyer original por el selector de archivos. Revisa el recorte que impone el panel; conserva la información de hora y precio en la descripción si el recorte la omite.
6. Marca entrada de pago cuando corresponda. Sólo introduce una URL de venta si se ha comprobado que es la correcta. No inventes tickets.
7. Revisa Resumen; publica sólo bajo la autorización aplicable. Comprueba después la fila Publicado y la ficha pública. Obtén el ID del enlace Ver.
8. No contrates Boost ni otras promociones pagadas.

## Songkick

1. La cuenta Tales4theTillerman ya gestiona el artista 10418553. Reutilízalo. No vuelvas a crear el artista.
2. Abre Events/calendar y busca la fecha y recinto. Si ya existe, usa Edit existing event. Si no, Add event → Concert.
3. Selecciona recinto existente por nombre y ciudad, fecha y artista principal T4T. No uses la hora de apertura como hora de actuación: distingue los controles. Incluye hora y precio explícitos en Additional details cuando el panel no tenga un campo adecuado.
4. Usa el enlace oficial en detalles y la imagen si el formulario o edición posterior permiten adjuntarla. Si Songkick no ofrece flyer, registra esa limitación; no marques flyer como sincronizado.
5. Guarda el evento autorizado, lee la página resultante y su ID, y verifica otra vez en calendar/public event. Si Songkick señala un posible duplicado, resuélvelo antes de crear.
6. Para distribución, consulta Manage all y registra los identificadores requeridos por Bandcamp/otros. Tener un evento en Songkick no demuestra que la distribución ya se haya producido.
